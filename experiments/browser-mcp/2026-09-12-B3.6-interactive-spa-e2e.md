# B3.6 — Interactive JS-rendered SPA E2E（browser-lab / Playwright MCP）

> **实验类型**：runtime E2E（真实 DSH 实例 + 真实 MCP + 真实 Chrome + live web）。
> **结论**：**Interactive JS-rendered SPA E2E: PASS** —— Browser MCP 从「tool invocation PASS」升级为「可驱动 JS-rendered SPA 并改变服务端结果集」。
> **与 B3.5 的关系**：B3.5 只验证 `example.com` 上的 `browser_navigate` + `browser_snapshot`（tool invocation）。**本记录是独立的新阶段 B3.6，不替换 B3.5 的历史记录。**
> 证据等级：`[FACT]` / `[INFERENCE]` / `[UNKNOWN]`。本记录中的 runtime 事实**均由 session event log 直接核对**（见 §6）。

---

## 1. 实验目标

验证 Browser MCP 能否在**真实 JS-rendered SPA**（而非静态示例页）上完成**交互**并**改变页面状态与服务端结果集**：

```
DSH Agent
  → dsh-mcp-client
  → MCP (stdio)
  → @playwright/mcp
  → Playwright
  → Chrome
  → live web（真实招聘 SPA）
  → accessibility tree
  → UI interaction
  → 页面状态变化
```

## 7. 结论

### [FACT]
1. **Interactive JS-rendered SPA E2E: PASS**。已验证：navigate → accessibility snapshot → 页面结构理解 → 识别 interactive elements → 用 `[ref=eN]` 定位 → click → 再次 snapshot → 状态对比 → **真实筛选状态改变 → 服务端结果集改变**。
2. `browser_click` 已在本机 MCP 链路上**实际调用成功**（`target: e143`）。
3. 结果集：`167 → 147`；分页：`17 → 15`；URL 新增 `location=CT_128`。
4. Chrome 由 `playwright-mcp --browser=chrome` 以 `--remote-debugging-pipe` + profile `mcp-chrome-79b2345` 启动。

### [INFERENCE]
1. 用户 prompt 只描述了目标（打开页面、取 snapshot、筛选），**具体用哪个 ref、点哪个元素由模型依据 accessibility tree 自行判断** —— 说明该链路具备"语义级"操作能力，而非脚本化点击固定坐标。

### [UNKNOWN]
1. console **1 error / 4–6 warnings** 的具体内容与原因。
2. 更复杂交互尚未系统验证：复杂搜索、多条件组合筛选、详情页深层导航、翻页、表单。
3. `@playwright/mcp@latest` 的版本漂移风险与兼容边界。
4. 多 MCP server 共存、MCP 工具在不同 agent preset 下的可见性裁剪。
